# Forces & Interactions — Interactive Learning Lab

An **easy, interactive, runnable** lesson built from two Chapter 5 source files:

- **Lecture Outline** (`05_LectureOutline.ppt`) — *Conceptual Physics* (Hewitt): Newton's Third Law of Motion & Vectors
- **Test Bank** (`05_Test_Bank.doc`) — 22 graded multiple-choice questions

Everything lives in a single file — **`index.html`**. No installs, no internet, no build step.

## ▶️ How to run

Just open `index.html` in any web browser (double-click it, or drag it into a browser tab).

```
# optional: serve it locally
python3 -m http.server 8000
# then visit http://localhost:8000
```

## What's inside

| Tab | What you do |
|-----|-------------|
| 📘 **Learn** | Bite-sized lessons: interactions, action–reaction pairs, same-force/different-mass, defining a system, and vectors — straight from the lecture outline. |
| 🚀 **Action–Reaction Lab** | Pick an interaction (hand & wall, rocket & gas, cannon & ball, you & Earth…) and see the two **equal-and-opposite** force arrows that act on **different objects**. |
| 💥 **Mass & Acceleration** | Slide the masses and force, then **fire the cannon**. Watch how equal forces give unequal accelerations via **a = F/m**. |
| ➗ **Vector Builder** | Adjust a horizontal and vertical vector; the app draws the parallelogram and computes the resultant with **R² = H² + V²**. Includes the 3–4–5, 80–60, and running-in-the-rain presets. |
| 📝 **Quiz** | All **22 test-bank questions** with instant feedback, worked explanations, progress bar, and a final score. |

## How the two lectures connect

The **lecture outline** supplies the concepts and live simulations; the **test bank**
supplies the self-check quiz. Concepts you read in *Learn* are the exact ideas tested in
*Quiz*, and the simulations let you *see* why each answer is what it is (e.g. the cannon
sim explains why a bus and a bug feel the same force but not the same acceleration).
