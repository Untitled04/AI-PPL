# AI-PPL

Study guides that turn course slide decks into **teachable, interactive, easy-to-read** notes.

Each guide merges two kinds of classroom material into one flow:
- 🧠 **Concept Checks** — from the in-class *Clicker Questions* (these *explain* the ideas).
- 🛠️ **Worked Examples** — from the *Next-Time Questions* (these *show the ideas in action*).

Answers are hidden behind collapsible ▶️ toggles on GitHub, so you can **think first, then reveal**.

## How to study with these

1. Read a section's short explanation.
2. Try the **Concept Check** question *before* opening the answer.
3. After a few sections, work the **Examples** end-to-end.
4. Use the **cheat sheet** and **answer key** at the bottom to review fast.
